# 이벤트 스토리 - 네가 없는 사이에 보내는 편지
{{ story_badge('battery-low', '가끔 등장') }}
교주를 대신에 몰래 편지를 써주고 있던 네르는 진짜 교주를 부르기 위해 에슈르를 찾아간다.
하지만 에슈르는 그것보다 솔직하게 털어놓는 편이 낫지 않냐는 조언을 해준다.

다야 몰래 교주의 편지를 대신 쓰고 있던 네르는 한계에 다다랐고 결국 에슈르에게 부탁해서 차원문을 열어 교주를 불러오려고 한다. 하지만 에슈르는 현실적으로 그건 좋은 방안이 아니라며 솔직하게 털어놓고 전부 사과하는 것이 어떻겠냐고 한다. 에슈르의 설득에 네르는 수긍하고 다야에게 사실 자신이 지금까지 교주의 편지를 전부 대신 쓰고 있었다는 것을 밝히고 사과한다.
