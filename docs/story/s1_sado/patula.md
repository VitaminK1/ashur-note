# 사도 스토리 - 파트라

## 에피소드 2 - 에심당 디펜스
???+ Abstract
    에슈르가 자리를 비우고 파트라 혼자 빵집을 맡은 날, 에르핀이 기껏 진열해둔 빵을 다 털어가는 것에 분노한 파트라는 결국 민트 빵을 진열해서 에르핀을 막아낸다. 그러나 민트 빵 때문에 손님이 아무도 안와서 돌아온 에슈르에게 혼난다.
{{ story_badge('battery-low', '가끔 등장') }}


## 에피소드 5 - 멘토와 멘티의 만남
???+ Abstract
    교단에서 우연히 피코라를 마주친 파트라. 서로 인사 나누다 피코라가 에슈르를 깎아내리자 열받은 파트라는 그녀와 신경전을 벌인다. 서로의 스승을 비난하던 중 교주와 에슈르가 서로의 멘티를 칭찬하며 대화하는 걸 듣고 둘은 반성하며 화해한다.
