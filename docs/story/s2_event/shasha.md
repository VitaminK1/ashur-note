# 이벤트 스토리 - 불 붙은 불행 속 쓰나미
{{ story_badge('battery-medium', '보통 등장') }}
파트라가 에심당의 아르바이트생이라 에슈르를 가끔 언급한다. 그리고 후반부에 샤샤가 화재를 진압할 때 잠깐 등장해서 얘기한다.

## 에피소드 1 - 불행한 화재
{{ story_badge('battery-outline', '언급됨') }}
샤샤와 파트라는 산책을 하러 나온다. 샤샤가 도시락을 챙겨왔냐고 묻자 파트라는 에심당에서 알바할 때 빵 몇개 몰래 챙겨놨다고 한다. 샤샤가 그래도 되는지 걱정하지만, 파트라는 에슈르는 성격이 단순하니까 말만 잘하면 충분히 넘어갈 수 있으니 걱정 말라며 산책을 즐긴다.

그러다 마녀 왕국으로 돌아가던 바리에를 만나는데, 보통의 물로는 꺼지지 않는 신기한 불이 퍼지는 바람에 카트를 못 쓰게 되는 상태였다. 다급해진 바리에는 때마침 만난 파트라에게 책 몇 권만 대신 보관해달라고 부탁한다. 파트라는 에심당 책장에 몰래 꽂아넣겠으니 나중에 본인의 이름을 말하고 책장에서 가져가면 될거라 하고, 바리에는 고마워 하며 알겠다고 답한다.

## 에피소드 3 - 불행한 난동
{{ image('story/s2_event_shasha_1.png', caption='기억 조각 - 부수적인 피해') }}
{{ story_badge('battery-outline', '언급됨') }}
샤샤가 우연히 동굴에서 텀블러를 발견한다. 그 텀블러로 물을 뿌려 무사히 불을 끄고 파트라와 함께 원래 자리로 돌려놓으려 하는데 텀블러가 갑자기 난동을 부려 파트라, 샤샤, 가비아한테까지 마구잡이로 물대포를 쏘아댄다. 물대포에 맞은 파트라는 에슈르한테 빵으로 얻어맞은 것처럼 아프다고 말한다.

샤샤는 추가적인 피해를 막기 위해 텀블러를 데리고 홀로 깊은 숲으로 향한다.

## 에피소드 6~7 - 불행 속 대화재~불행을 부르는 텀블러
{{ story_badge('battery-high', '자주 등장') }}
샤샤가 정령 호수에서 나이아와 얘기하던 도중, 파트라가 급히 달려와 에심당에 불이 났다며 도와달라고 말한다. 샤샤가 요정왕국에 도착했을 때는 이미 늦어 불이 요정왕국 전체를 태우고 있었다. 샤샤는 텀블러의 힘을 이용해 화재를 진압해 나가지만, 수압이 너무 세서 건물까지 모조리 부순다.

마지막으로 에심당만 남았을 때 샤샤가 빵집이 부셔져도 괜찮냐고 물어보자, 에슈르는 {=="이젠 불끈다고도 안 하는구나"==}라며 책 몇권이라도 축축한 채로 건지는 게 낫다는 반포기 상태의 심정으로 허락한다. 그래도 그동안 물을 많이 써서 그런지 호수의 물이 많이 줄어들어 수압이 약해진 덕에 에심당은 그나마 덜 부셔졌다.

이후 화재가 진압되어도 텀블러가 말을 안듣자 샤샤가 본격적으로 화를 내는데, 에슈르는 텀블러가 내팽겨쳐지는 걸 보면서 {=="요정이었다면 엄청 아팠겠다"==}며 샤샤한테는 절대 까불지 않겠다고 다짐한다.

## 여담
{{ youtube('lvuzi8UP_sg', caption='불 붙은 불행 속 쓰나미 테마극장 PV') }}
+ 에슈르는 본편의 비중이 아주 낮은 대신 PV에서 많이 등장했다. 내용이 크게 다른데, PV에서는 에슈르가 오븐 규정 온도를 잘못 설정해 실수로 화재를 일으킨다. 에슈르는 요정왕국에 소방관이 없으니 파트라와 함께 빵을 쌓아 기우제를 하는데, 물의 기운이 부족하다며 나이아를 빵 높이에 맞도록 파묻으며 기도한다. 그러다 샤샤가 등장해 화재의 원인인 건물을 부수면 된다고 하자 그걸 말린다.
