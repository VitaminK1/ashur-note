## 이마트24 콜라보
{{ youtube('fbg1D6ecU9Y', caption='이마트24 콜라보 영상') }}
2025년 12월에 진행되는 이마트 24 콜라보 영상에서 등장한다. 에르핀을 위해 만들 시제품들을 버터에게 소화제까지 사용해 테스트해본다. 그런데 갑자기 에르핀이 마지막에 등장해서 빵들을 마구 먹어치우며 버터에게 포장지와 띠부씰을 던진다. 결국 버터의 100번이 쌓이며 빵집이 또 폭발당하고 만다.
{{ image('others/event/emart24.png', width=700, height=300, caption='이마트 24 굿즈 목록') }}
이벤트 굿즈 일부와 빵 표지에도 등장한다. '에슈르의 카라멜맛 쿠키'로 가격은 2,200원. 띠부씰에는 등장하지 않았다.
